<h1>Optimal packing solver for One item in a truck</h1>
This project is a usefull tool for my gf who works in logistics and spends countless minutes on figuring out the best loading strategy.
The algorithm is using a greedy aproach and works with stackable boxes and pallets(limited in their rotation)
